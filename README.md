3RVX is a customizable on-screen display (OSD) and hotkey tool for Windows systems.

Homepage: [3RVX.com](https://3RVX.com)

Features
--------
* Volume control
* Microphone control
* Brightness control (DDC/CI)
* Keyboard indicator (Lock Keys, Media Keys)
* Eject indicator (Removable media)
* Customizable skins, icons and hotkeys for all of the above

Building
--------
You can build 3RVX with [Visual Studio](https://www.visualstudio.com/). There are no external dependencies; clone and compile.

History
-------
3RVX is an overhaul of 3R-1C, an older application written in .NET by Matthew Malensek (pogrelz) in 2003. It is the last surviving program of a line of many different skinnable applications, namely Skalc, Sally, Bezelizer, amongst many others.

The original purpose of the program was bringing the Mac OS X volume bezel to Windows, but its scope grew way beyond that relatively early into its development, thus being renamed to 3RVX.

The last version that used .NET was 3RVX 2.5, after which, in late 2009, Matthew Malensek started to rewrite the program from scratch in C++ using the Windows API. This final overhaul would become 3RVX 3, and after some time, although having an almost complete program, major development would stall by 2017.

This project was originally forked only to restore glass effects on modern Windows versions without any kind of version spoofing, but after looking up the history of the program, I decided to continue working on it.
